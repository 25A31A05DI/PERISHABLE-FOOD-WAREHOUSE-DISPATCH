# PROJECT REPORT
# PERISHABLE FOOD WAREHOUSE DISPATCH SYSTEM

## 1. Introduction
The Perishable Food Warehouse Dispatch System is a Java-based application developed to manage food products that have expiry dates.

In warehouses, some food products expire earlier than others. This project uses a Min-Heap data structure to dispatch food batches with the earliest expiry dates first.

## 2. Problem Statement
Managing perishable food products manually can cause delays and food wastage. Therefore, an automated system is required to organize food batches and dispatch them according to expiry dates.

## 3. Objectives
- To manage perishable food items.
- To reduce food wastage.
- To dispatch food based on expiry dates.
- To maintain food batch details.
- To improve warehouse management.

## 4. Technologies Used
- Programming Language: Java
- Data Structure: Min-Heap
- Concepts: Object-Oriented Programming
- Date Handling: Java LocalDate
- Development Environment: Visual Studio Code / GitHub Codespaces

## 5. Modules
### FoodBatch Module
Stores batch ID, food name, quantity, and expiry date.

### MinHeap Module
Organizes food batches based on expiry dates and keeps the earliest-expiring batch at the top.

### Warehouse Module
Manages adding food batches, displaying inventory, and dispatching food.

### Main Module
Provides the menu-driven interface for users.

## 6. Working Procedure
1. Start the application.
2. Select an operation from the menu.
3. Add food batch details.
4. View the available inventory.
5. Dispatch the batch with the earliest expiry date.
6. Exit the application.

## 7. Advantages
- Easy to use.
- Saves time.
- Reduces food wastage.
- Uses an efficient data structure.
- Helps manage warehouse inventory.

## 8. Future Enhancements
- Store inventory permanently using a database.
- Add a graphical user interface.
- Generate expiry notifications.
- Add user login and authentication.
- Support multiple warehouse locations.

## 9. Conclusion
The Perishable Food Warehouse Dispatch System demonstrates how Java and the Min-Heap data structure can be used to manage perishable food products efficiently. It prioritizes food batches based on expiry dates and helps reduce food wastage.
