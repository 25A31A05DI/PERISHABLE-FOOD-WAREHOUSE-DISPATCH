
# Perishable Food Warehouse Dispatch System

## Description
The Perishable Food Warehouse Dispatch System is a Java-based application designed to manage perishable food items in a warehouse. It uses the Min-Heap data structure to prioritize food items based on their expiry dates.

The system ensures that food items with the earliest expiry dates are dispatched first, helping to reduce food wastage and improve warehouse management.

## Features
- Add food items to the warehouse.
- Manage food inventory.
- Prioritize items based on expiry dates.
- Dispatch items with the nearest expiry date first.
- Validate food expiry dates.
- Display available inventory.

## Technologies Used
- Java
- Data Structures and Algorithms
- Min-Heap
- Object-Oriented Programming (OOP)

## Objective
To reduce food wastage by ensuring that perishable food items are dispatched in the correct order based on their expiry dates.

## Conclusion
This project demonstrates the practical application of data structures and algorithms in real-world warehouse management systems.
